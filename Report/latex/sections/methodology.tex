\section{Methodology}
\noindent\textit{Author: Nguyễn Trọng Đạt}


This section describes the design of the system. We outline the data
collection and preprocessing of Vietnamese and English CV--job description
pairs, the structured information extraction pipeline, the retrieval
components, and the job-fit scoring module. We also explain how the system
produces explanations for each score so that recruiters can inspect the
reasoning behind a ranking.
